The Engine

Six process-mining metrics

Every metric is a pure TypeScript function over the raw event log — no external libraries, no black boxes. Each is unit-tested with hand-crafted logs where the answer is known in advance.

Variant Analysis
Identifies every distinct execution path (sequence of activities) and how many cases followed it. High variant counts signal unpredictability — hard for agents to handle.
Top-Variant Coverage
What fraction of cases follow the single most common path? 85%+ means the process is highly standardised — ideal for automation.
Rework Rate
% of cases where any activity was repeated (e.g. "Validate Invoice" appearing twice). Rework means the process has unstable states — agents get confused.
Exception Rate
% of cases containing a rollback activity (Cancel, Reject, Return to Requester). High exception rates signal human-judgment moments that agents shouldn't override.
Cycle Time
Average and median duration from first to last event per case. Faster processes have shorter agent feedback loops and faster ROI realisation.
Bottleneck Detection
The activity with the largest average wait before it. Surfacing bottlenecks is the first optimisation signal — the step where an agent could have the most impact.
The Score

AI-readiness score — fully explainable

Each process gets a score from 0 to 100 computed from five normalised factors with explicit weights. The score is never a black box — every factor's raw value, weight, and contribution to the final score is returned and rendered. This mirrors ARIS's governance-first design philosophy: "nothing gets deployed until you've seen what it will do."

Weighted scoring formula
Standardization
30%
= topVariantCoverage — how predictable is the execution path?
Stability
25%
= 1 − reworkRate — how often does work need to be redone?
Cleanliness
20%
= 1 − exceptionRate — how often does a human need to intervene?
Volume
15%
= log-normalised case count — more volume = more ROI from automation
Speed
10%
= normalised inverse cycle time — faster processes respond better to agent loops
